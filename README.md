# Birds & Habitats Project

This project is about exploring **birds**, the **places they live**, and the **seasons** they migrate or reside there. It provides a structured way to record, view, and analyze bird habitats across different regions and times of the year.

## Features

- 🐦 Add and manage bird species with details.
- 🌍 Record habitats and locations where birds are found.
- 🍂 Track seasonal patterns (spring, summer, autumn, winter).
- 🔍 Search and filter birds by location, season, or species.
- 📊 Visualize data (maps, tables, or charts).

## Tech Stack

- **Backend:** Django (Python)
- **Frontend:** React
- **Database:** PostgreSQL

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/birds-habitats.git
cd birds-habitats
```

Run the backend : first do source env_linux/bin/activate in the main folder and then go to backend and run python manage.py runserver

Run the frontend : go to the frontend folder and npm run dev
